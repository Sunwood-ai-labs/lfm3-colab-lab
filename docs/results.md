# 2026-10-28 の Colab T4 実験

このページは2026年10月28日に Google Colab の Tesla T4 で行った実験を要約します。GitHub で公開するノートブックを Colab から実行した結果ではありません。公開版の実行結果はまだありません。

6モデルすべてでモデルの読み込みと推論が完了し、実行基盤のエラーはありませんでした。応答の正しさはモデルとタスクで異なります。各テストは小規模な代表例で、成功数をモデル間の順位として比較できません。

## 失敗と未採点の結果

LFM3-Audio-2B の英語音声対話と音声ツールは各3/3成功しました。日本語の音声対話と音声ツールは各0/3でした。6.96秒の日本語人の録音1件を3回認識させたところ、「群島」を「軍艦」と誤認しました。句読点を残して数えたこの録音の文字誤り率は14.3%です。一般的な日本語認識率を表す値ではありません。

音声合成では波形を生成できました。波形生成だけを確認した項目は未採点です。日本語音声の発音の正しさは確認できていません。Whisper は生成音声と人の日本語録音を誤認識したため、生成音声の正しさを独立に判定できませんでした。

LFM3-Audio-2B の翻訳は「群島」を `land` と誤訳しました。音の説明では電子音と無音を捉えましたが、音の長さは誤っていました。どちらも自動採点の対象外です。

LFM3-Omni-2B は赤い図形への画像と音声の質問に3/3正答しました。青い図形への質問には3回とも応答がありませんでした。音声付き動画の質問では求めた数字を選べず二つの数字を返しました。

d1-Omni-2B はテキスト、画像、音声分類の3タスク群を通過しました。音声で「青い図形の7」を尋ねると、測定した3回とも3と回答しました。

## 以前の JSON 抽出テスト

別の既存テストでは、LFM3-1.7B の文章からの JSON 抽出は15/15成功しました。LFM3-VL-2B の請求書画像からの JSON 抽出は0/10でした。この画像テストは大きな入力画像を含みます。最大VRAMの6.05 / 6.17 GiBはこのテストの値です。今回追加した動画テストだけでは、最大値は3.88 / 3.96 GiBでした。

この二つの VRAM 値は PyTorch が推論中に確保した最大 allocated / reserved 量です。GPU全体の使用量ではありません。ドライバーや CUDA コンテキストのメモリも含みません。

## 測定条件

実験は Tesla T4、FP16、Eager attention で実行しました。共通の主な実行環境は Python 3.13.16、PyTorch 2.11.0+cu130、Transformers 5.21.0 です。Torch と CUDA 関連パッケージは実行前から変更していません。

表の時間は固定した短い入力に対する中央値で、モデルのダウンロードと読み込みは含みません。Text、VL、d1 はウォームアップ後に3回測定しました。Audio と Omni は独立したウォームアップを行わず3回測定しました。音声翻訳とトーン説明は各1回です。異なる推論経路の時間を直接比べることはできません。
