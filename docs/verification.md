## 何を確認したか

ノートブックの公開版と実行に使った入力ファイルが同じこと、表示されたコードのコミット、モデルのリビジョン、実験スクリプトのハッシュを照合しました。ZIPの破損検査、6モデルのT4・FP16、記録された速度とVRAM、セルのエラー出力がないことも確認しています。元のTorchとCUDA関連パッケージは維持されました。

自由入力欄には「18 と 24 を足した答えを、一文で教えてください。」を渡しました。モデルは42を含む回答を返しましたが、説明を添えた2文でした。これは未採点の自由入力例で、すべての指示に従うことを保証する試験ではありません。

## 実行条件と結果の単位

公開版の最初の設定は各ケース1回です。参考の繰り返し測定とは別の記録として扱います。速度を繰り返して測る場合は、ノートブック先頭の `REPEATS` を3にしてください。

| モデル | 今回の検査通過 / 記録数 | 通過判定なし | 誤答など |
| --- | ---: | ---: | ---: |
| LFM3-1.7B | 2 / 2 | 0 | 0 |
| LFM3-VL-2B | 3 / 3 | 0 | 0 |
| LFM3-Audio-2B | 9 / 15 | 4 | 2 |
| LFM3-Omni-2B | 1 / 3 | 0 | 2 |
| d1-2B | 2 / 2タスク群 | 0 | 0 |
| d1-Omni-2B | 3 / 4タスク群 | 0 | 1 |

この表はモデルの順位ではありません。モデルごとに試した機能と通過の基準が異なります。Audioの通過には、音声の波形を生成できたかだけを調べるケースも含みます。音声認識は文字誤り率を、翻訳と音の説明は出力内容を別に確認します。d1の1タスク群には複数の質問が入っています。

日本語の音声対話や複合入力には誤答が残っています。これらは実行基盤のエラーと区別して、そのまま記録しています。[以前の繰り返し測定と限界](results.md)も参照してください。
