# LFM3 Colab T4 experiments

[Open the notebook in Colab](https://colab.research.google.com/github/Sunwood-ai-labs/lfm3-colab-lab/blob/main/notebooks/LFM3_Colab_T4.ipynb)

Run examples for text, image and video, audio, mixed input, classification, and extraction on a Google Colab Tesla T4. The notebook runs six Liquid AI models and downloads their weights from Hugging Face at runtime.

The repository records two separate runs from 2026-10-28. The reference experiment used repeated measurements. The public notebook validation used one repetition per case. Their pass counts use different tasks and scoring rules, so they do not rank the models.
